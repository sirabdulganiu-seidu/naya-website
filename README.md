# Nanumba Youth Association (NAYA) Website

Static, mobile-first website starter designed for low-cost/free static hosting.

## Stack
HTML5, CSS3, JavaScript. No database or server required for the first version.

## Pages
Home, About, Leadership, Advocacy, Programs, Projects, News, Events, Gallery, Membership, Contact.

## Before launch
- Replace all placeholder text with verified NAYA information.
- Add official logo and photographs.
- Replace contact and social-media details.
- Replace YOUR-DOMAIN.org in sitemap.xml and robots.txt.
- Connect forms to an approved form/email service.
- Test all links and mobile layouts.
- Add Google Search Console after the domain is connected.

## Future
If NAYA needs self-service news/events/gallery management, membership accounts, document management or event registration, connect this frontend to Django/PostgreSQL later.
